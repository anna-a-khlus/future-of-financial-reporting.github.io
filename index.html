The Idea

What is Automated Commenting, exactly?

Scope

Who uses it

Top Management
Operational Controllers + Top Management
01

ERIC triggers generation

When ERIC data is available, it automatically triggers the comment generation pipeline — no manual kick-off needed.

02

Quantitative comments via MAISTRO

Numbers are explained automatically using MAISTRO skill — no additional development required.

03

Agent generates qualitative comments

The agent applies specific rules per deviation type & effect, then cross-validates qualitative against quantitative comments.

04

Controller validates

Human-in-the-loop: controller reviews and approves comments before they are saved to the database.

05

MAISTRO monthly report

Validated comments feed the orchestrator agent, which assembles the complete monthly report automatically.

Foundation

What makes it work

  • Commenting rules & patterns Research run on historical comments for every effect & AwA combination
  • RAG architecture Retrieval-Augmented Generation ensures contextually accurate commentary
  • Solid agent rules Every deviation type has a dedicated rule set the agent follows strictly
  • Cross-validation Agent validates qualitative output against quantitative data before passing to controller
